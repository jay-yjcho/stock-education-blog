# 주식 용어 백과사전

주식 용어 및 금융 상품에 대한 이해를 돕는 교육 블로그입니다. 이 블로그는 주요 금융 상품과 전략을 설명하고, 각 상품의 정의, 특징, 그리고 국내 시장에서 유명한 종목들을 소개합니다.

## 기능

- 주요 주식 용어 및 금융 상품 설명
- 전략별 정의, 특징, 예시
- 국내 시장에서 유명한 종목 소개
- 교육적 콘텐츠 중심의 구성
- 애드센스 수익화를 위한 구조

## 주요 콘텐츠

- 커버드콜 (Covered Call)
- 스트래들 (Straddle)
- 스트렝글 (Strangle)
- 아이언콘도 (Iron Condor)
- 프로텍티브풋 (Protective Put)
- 기초 파생상품 개념
- ETF (상장지수펀드)
- 국내 주식 투자
- 주식 분석 방법

## 설치

1. 이 저장소를 클론합니다:
   ```bash
   git clone https://github.com/your-username/stock-education-blog.git
   ```

2. 의존성을 설치합니다:
   ```bash
   npm install
   ```

3. 개발 서버를 시작합니다:
   ```bash
   npm run dev
   ```

## 빌드 및 배포

```bash
npm run build
npm run start
```

## 애드센스 설정

블로그에 애드센스를 적용하려면 다음을 수행하세요:

1. `pages/_app.js` 파일에서 `ca-pub-XXXXXXXXXX` 부분을 실제 게시자 ID로 변경합니다.
2. 각 페이지에서 사용되는 광고 슬롯 ID를 실제 사용하는 ID로 변경합니다.
3. Google AdSense 계정을 통해 블로그를 등록하고 승인을 받습니다.
